# .prettierrc 欄位中文註解

> 原始設定檔：`/.prettierrc`（維持 JSON、未改動）

```json
{
    "singleQuote": true,
    "tabWidth": 4,
    "semi": true,
    "printWidth": 100,
    "trailingComma": "all"
}
```

## 欄位說明

- `singleQuote: true`
  - 使用單引號 `'`，例如：`const name = 'pablo';`
  - 若為 `false`，則偏好雙引號 `"`。

- `tabWidth: 4`
  - 每層縮排使用 4 個空白寬度。

- `semi: true`
  - 在語句結尾加上分號 `;`。

- `printWidth: 100`
  - 單行長度建議上限為 100 字元。
  - 超過時 Prettier 會自動換行以維持可讀性。

- `trailingComma: 'all'`
  - 在可行的多行結構結尾加上尾隨逗號（如物件、陣列、函式參數等）。
  - 有助於減少版本控制中的 diff 變動。
